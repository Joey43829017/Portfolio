Numerical Modeling of a Vibration Isolation System — Parts 1–3

Curve Fitting: Fitted force-displacement data to both a third-order polynomial (SSE = 1,716.6) and a physics-guided nonlinear model k₁x + k₂tan(k₃x) (SSE = 1,687.9). The physics model fit better with lower residual error.

Numerical Differentiation: Computed numerical derivatives using second-order central differences at interior points and one-sided formulas at boundaries. Confirmed O(h²) convergence on the log-log error plot (slope ≈ 2).

Numerical Integration: Integrated strain energy via trapezoidal rule (observed order ≈ 2) and Simpson's 1/3 rule (observed order ≈ 4), both converging to the exact analytical value of 1.288 N·m.

Numerical Modeling of a Vibration Isolation System — Parts 4–5

Solver Analysis: Modeled forced vibration with m=12 kg, c=95 N·s/m, k=4200 N/m using MATLAB's adaptive ODE45 solver (4th/5th-order Runge-Kutta). Confirmed tolerance independence (max diff = 2.4e-5 m between default vs tight tolerances).

Time Stepping: Verified adaptive time stepping from the dt-vs-time plot — step size varied throughout the run rather than remaining constant, confirming the solver auto-adjusts for accuracy.

Numerical Modeling of a Vibration Isolation System — Parts 4–5 (continued)

Frequency Analysis: Prepared uniform time grid at fs ≈ 500 Hz for accurate FFT analysis. Frequency response showed dominant peak at 2.5 Hz (magnitude 3.04e-2) and secondary at 7 Hz (1.41e-3), demonstrating the system acts as a low-pass vibration filter.
