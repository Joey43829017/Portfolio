Arduino Prototype System

ME 2900 Control Systems Engineering Project

Problem Statement

The project required designing and implementing an embedded control system using Arduino microcontrollers to demonstrate practical applications of sensor integration, actuator control, and real-time data processing in mechanical systems.

Key Objectives:

  • Implement multi-sensor data acquisition system
  • Create closed-loop control with real-time feedback
  • Demonstrate MATLAB/Simulink model-to-physical validation

Engineering Approach

The Arduino prototype integrated multiple sensor types with a central microcontroller for data acquisition and control logic implementation. The system architecture included:

System Architecture:

Sensors → ADC (10-bit) → Arduino MCU → Control Algorithm → Actuators

Data Flow: Sensor Raw → Filtered → PID Controller → Actuator Command

Sampling Rate: 1kHz for position control, 50Hz for general monitoring

Component Selection:

  • Arduino Mega 2560 (32 MHz, 4 UART, 54 PWM pins)
  • ENC potentiometer encoders for position feedback
  • Temperature sensors (LM35) for thermal monitoring
  • Solenoid valves for pneumatic actuation control

Analysis and Control Design

MATLAB Modeling:

System Transfer Function:
G(s) = K / (τs + 1)

Where:
K = System gain
τ = Time constant from experimental step response

Discretization for Arduino Implementation:
y[k] = G(z)u[k] + D(z)w[k]

PID Controller in Z-domain:
U(z) = KpE(z) + Ki(1/z)E(z) + Kd(z-1)/z E(z)

Control Algorithm Implementation:

  • Position control using PID algorithm
  • Feedforward compensation for known disturbances
  • Anti-windup protection for integral term

Implementation Details

C++ Code Structure:

#include <Arduino.h>
#include "sensor_lib.h"

// System State Variables
float error, previousError, integral = 0;
int lastTime = millis();

// PID Control Loop
void controlLoop() {
   error = targetPosition - currentPosition;
   integral += error * (SAMPLE_INTERVAL / INTEGRAL_PERIOD);
   output = Kp*error + Ki*integral + Kd*(error - previousError);
   previousError = error;
   setActuator(output);
}

Key Achievements:

  • Achieved stable closed-loop control with PID tuning
  • Validated MATLAB/Simulink models against physical implementation

Lessons Learned:

  • Sampling Rate Importance: Higher sampling rates (1kHz vs 50Hz) significantly improved control response and stability margins
  • Noise Filtering: Simple moving average filter reduced sensor noise without introducing significant phase lag
  • Code Optimization: Critical control loop functions must be deterministic—avoid blocking operations
  • PID Tuning Methodology: Ziegler-Nichols method provided good starting point, but manual fine-tuning improved performance by 30%
